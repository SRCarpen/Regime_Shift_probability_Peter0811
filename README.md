See the PDF 'Sequence_R_Scripts_PeterLake_2008-2011.pdf' for instructions to repeat the calculations and figures for the manuscript 'Odds of Regime Change in a Predator-Addition Experiment'.  The R scripts use food web data from Peter Lake in 4 years to build a Langevin model for chlorophyll using with cubic b-splines, find the equilibria, bootstrap the standard deviations of the equilibria, and use odds-ratio (logistic) regression to construct a curve for probability of chlorophyll regime shift versus population of adult largemouth bass in the lake.
